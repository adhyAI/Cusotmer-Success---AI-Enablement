# Research Dashboard — Implementation Spec (v3)

## Design Philosophy
- **Stakeholder-first**: Every view is anchored to people, not abstract themes
- **Editable inline**: Click any field → edit it → it saves to state
- **Simple but complete**: 9 tabs, each with one clear job
- **Populated with real data**: Always use actual research data from the analysis
- **Pipeline-aware**: Dashboard reflects the current stage of the research pipeline

## Tech Stack
- React with useState, useMemo, useCallback
- Tailwind utility classes only (no custom CSS)
- lucide-react for icons
- No localStorage — all state lives in React state

## Tab Specs

### Tab 1: Stakeholders (DEFAULT VIEW)
Sortable table + expandable row detail.

Columns: Tier | Segment | Name | Role | Team | Influence | Pain | Status | Date | Sentiment | Key Theme

New columns vs v2: **Segment** (Champion/Pragmatist/Skeptic/Uninvolved badge), **Influence** (High/Med/Low), **Pain** (High/Med/Low)

Inline editing: Status (dropdown), Sentiment (dropdown), Segment (dropdown), Date (date input), Notes (textarea on expand)

Expandable row: click name → show quotes + notes + scheduling status panel below

Tier badges: indigo=Decision Maker, blue=Power User, slate=Adjacent, amber=Skeptic
Segment badges: green=Champion, blue=Pragmatist, red=Skeptic, gray=Uninvolved
Status colors: green=Complete, blue=In Progress, yellow=Scheduled, slate=Not Started

Add stakeholder: button at bottom opens inline form row.

---

### Tab 2: Themes
Card grid (2 columns). Each card: theme name (editable), confidence badge (green 4-5, yellow 3, red 1-2), stakeholder chips, top quotes (collapsed/expandable), workaround (editable), link to Problem Statement (Tab 7). Sort by Confidence / Frequency / Impact.

---

### Tab 3: Opportunities
Prioritized list with drag handles. Columns: # | Name | Stakeholders | Impact | Effort | Roadmap Bucket | Confidence. All inline editable. Drag to reorder. Add button at bottom.

---

### Tab 4: Roadmap
4 swimlane columns: Now / Next / Later / Parking Lot. Each card: initiative name, problem (1 line), stakeholder chips, confidence. Click to expand: validation needed, notes. Drag cards between swimlanes.

---

### Tab 5: Interview Planner
Two sections:
1. Coverage tracker: stakeholder list with status, red highlight on gaps (tiers with <2 complete), "next to interview" recommendation, scheduling status column.
2. Question guides: accordion by tier, each with questions + probes, all editable, "Copy guide" button per tier.

---

### Tab 6: Open Questions
Simple editable list: Question | Why it matters | Who to ask (stakeholder dropdown) | Status (Open/Answered/Deprioritized). Add question button. Filter by status.

---

### Tab 7: Problem Statements (NEW)
Card layout (1 column, full width). One card per problem statement.

Each card structure:
- **Header**: HMW statement in large bold text + Status badge (Draft/Validated/Accepted/Deferred — editable dropdown)
- **JTBD**: "When I..." narrative in italic, slightly smaller
- **5 Whys**: Collapsible accordion — numbered list from Surface → Root Cause, each step editable
- **Problem Brief**: Collapsible section with all fields editable inline:
  - Problem description, Affected personas, Impact, Root cause, Workaround, Constraints, Success metric
- **Footer**: Affected personas as chips + Theme link + "Copy Problem Brief" button

Sort by: Impact | Status | Theme
Filter by: Status | Persona | Theme

Colors:
- Validated: green badge
- Draft: yellow badge
- Accepted: indigo badge
- Deferred: gray badge

"Copy Problem Brief" button: copies the full problem brief as plain text to clipboard.

---

### Tab 8: Sentiment & Friction (NEW)

**Top half — Friction Heatmap:**
Grid layout: rows = Process Areas, columns = Teams.
Each cell shows the friction score (0–10) with background color:
- 0–2: bg-green-100
- 3–4: bg-yellow-100
- 5–6: bg-orange-100
- 7+: bg-red-100

Click any cell → slide-out panel showing:
- Which stakeholders mentioned this area
- Their top quotes about it
- Sentiment scores for those stakeholders

Row totals on the right. Column totals at the bottom. Sort rows by total friction descending.

**Bottom half — Sentiment Timeline:**
One sparkline per stakeholder showing sentiment score over time (date × score, range −2 to +2).
Color: blue above 0, red below 0.
Hover any data point → tooltip with date, score, and emotional markers.

**Convergence Alert Banner:**
If any process area has 3+ stakeholders flagging it, show: "⚠️ Convergence: [X] stakeholders across [Y] teams flagged [Area] as high-friction."

Filter controls: by team, by process area, by date range.

---

### Tab 9: Pipeline Status (NEW)

Three-column layout:

**Left column — Coverage Tracker:**
Progress bars per tier:
- Tier 1 (Decision Makers): X/Y interviewed (green if ≥80%, yellow if 50–79%, red if <50%)
- Tier 2 (Power Users): X/Y interviewed
- Tier 3 (Adjacent): X/Y interviewed
- Tier 4 (Skeptics): X/Y interviewed

Gap alerts in red: "No Tier 4 stakeholders interviewed yet"
Segment coverage: % Champion / Pragmatist / Skeptic / Uninvolved interviewed

**Center column — Scheduling Kanban:**
4 columns: Not Started | Reached Out | Scheduled | Complete
Each stakeholder shown as a small card with name, tier, segment badge.
Drag to move between columns (updates `schedulingStatus`).
Click card → show their scheduling pack (email, calendar invite, Slack DM).

**Right column — Next Actions:**
Auto-generated checklist based on current pipeline state:
- "Interview [Name] (Tier 1 — not yet scheduled)" → priority queue from Step B3
- "Reach out to [Name] (Reached Out 5+ days ago — no response)"
- "Run synthesis — 4 interviews complete since last synthesis session"
- "Fill coverage gap: no Skeptics interviewed yet"
- "3 open questions need follow-up interviews"

**Pipeline Health Score:**
0–100 score shown as a gauge. Calculation:
- Coverage % across all tiers (30 pts max)
- Average confidence score of themes (25 pts max)
- % of open questions answered (20 pts max)
- % of stakeholders with complete problem statements (15 pts max)
- Research calendar adherence (10 pts max)
